# COMMON STEPS
----------------------------------------------------------------
main banda folder and initial files panaayega
ab usse github par daal de
collaborators add kare


saare bande us repo se cloning karein
[VERY-IMPORTANT] apni branch create karein 
apna code usi branch mein likhen 
complete hone par commit dein aur push kr dein
infom karein teammates ko about the commit
merger banda fetch karega and merge karega and re-push karega


#  USE COMMONDS

1) **git init**
    isse hum apne gihub par connect hote hein matlab hamare repository se initialize hote hein
2) **git add .**
    isse hum hamara sare file ko github par upload kar sakte hein.
3) **git commit -m "your first commit"**
    isse hum commit kr sakte hein
4) **git push -u origin branch name**
    ye commond sare code ko apne branch me store kr leti hein github par
5) **git switch branch name**
    ye commond branch ko change krti hain
6) **git switch -c branch name**
    ye commond brach exchange krti hein aur agar wo branch existing hi nahi ho to wo us branch ko khud hi bana leti hein.
7) **git branch**
    ye commond github me se sare branch ko dikhati hein.
8) **git push origin main **
    ye commond github me main branch me code push krdeti hein.
9) **git fetch**
    ye commond github se code fetch kr leta hein.
10) **git pull**
    ye commond github me jo main branch he usmese sara code new branch me update krne ke liye use hoti hein.# COMMON STEPS
